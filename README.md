# 微明

在做 **Personal Agent**：一个本地优先、记忆可审计、能真正调用工具办事的通用个人 Agent。

## 它是什么

- 不是聊天壳：学习、编程、文档、决策共用一个 Agent 和一套长期记忆。
- 不是黑盒：记忆、上下文、模型、成本、工具和完成证据都可检查。
- 不是厂商锁定：数据本地，模型可替换，可导出。

## 现在在做什么

- 通用内核 + 用户自定义场景
- 带证据、时间和遗忘的长期记忆
- Intelligent UI、Office AI、内置查看器

项目还在早期：部分是原型，部分是设计，没实现的我不会写成已实现。

## 想找什么样的共创

- 架构反例：哪条设计在真实情况下会错
- 真实场景：你想用它做什么，现在哪里不行
- 记忆评测：怎样证明“记得对”
- 实现补丁：小而可验证
